# Suno Export Toolkit Share — инструкция (Samsung S10e / Android 12)

## 1. Самый быстрый сценарий через «Поделиться»

1. Открой песню Suno в браузере или приложении.
2. Нажми **Поделиться**.
3. Выбери **Suno Export Toolkit Share**.
4. Ссылка автоматически появится во вкладке **Suno URL**.
5. Нажми **Загрузить данные**, если хочешь проверить название/описание.
6. Нажми **UseSuno Downloader — открыть сайт**.
7. Ссылка уже скопирована в буфер. Вставь её в поле downloader и выполни доступное скачивание.
8. Вернись в Suno Export Toolkit.
9. Нажми **Найти последний аудиофайл в Download**.
10. Приложение переключится в **Файл / Backup Manager** и выберет свежий аудиофайл.
11. При необходимости добавь название, автора и lyrics.
12. Нажми **Создать backup package**.

Результат сохраняется в:

```text
Download/
└── Suno Export Toolkit/
    └── Название_YYYYMMDD_HHMMSS/
        ├── исходный аудиофайл
        ├── metadata.json
        ├── lyrics.txt
        └── Название_backup.zip
```

## 2. Обычная вставка URL

На вкладке **Suno URL** нажми **Вставить** или вставь ссылку вручную.

Поддерживаются:
- `https://suno.com/s/...`
- `https://suno.com/song/...`
- `https://suno.com/hook/...`

## 3. Поиск последнего файла

На Android 12 при первом нажатии **Найти последний аудиофайл в Download** приложение может запросить разрешение на чтение файлов/медиа. Разрешение используется только для поиска последнего аудиофайла в папке Download.

Если автоматический поиск ничего не нашёл, открой вкладку **Файл** → **Выбрать аудиофайл**.

## 4. Lab

Вкладка **Lab** предназначена для тестовой локальной сети. Она принимает localhost/private LAN и не предназначена для обычного Suno URL.

## 5. Тема

Приложение использует только светлую тему. Android system dark mode не должен включать тёмное оформление приложения.
